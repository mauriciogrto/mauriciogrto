# Mauricio Girotto

### Desenvolvo soluções web para problemas reais de operação.

Sou desenvolvedor web e de sistemas e fundador da [GRX Sistemas](https://grxsistemas.com.br/), na Serra Gaúcha, RS. Construo soluções para indústria, mobilidade e operações comerciais, da especificação à publicação.


**PHP · Laravel · React · MySQL/MariaDB · Python · Node.js**

## Projetos principais

| Projeto | A solução | Tecnologias |
| --- | --- | --- |
| [**LTECH Gestão**](https://github.com/mauriciogrto/ltech-gestao) | Gestão de máquinas e locações, checklists por QR code, manutenção, documentos comerciais e rastreamento por IMEI. | Laravel 12, PHP 8.2, QR code, flespi |
| [**Vai Bento**](https://github.com/mauriciogrto/vai-mobilidade) | Aplicativo de transporte público com mapa, linhas, paradas e integração com rastreadores GPS. | React, PHP, MariaDB, MapLibre |

## Outros projetos

- [Nesting a Laser](https://github.com/mauriciogrto/nesting-laser) — encaixe de peças DXF em chapas, com estoque, retalhos e exportação técnica em Laravel, Python e Node.js.
- [Força de Vendas](https://github.com/mauriciogrto/forca-vendas) — PWA comercial com importação de planilhas e montagem de orçamentos e pedidos.
- [Orçamentos (em revisão)](https://github.com/mauriciogrto/orcamentos) — gestão comercial multiempresa, comissão e geração de PDFs.
